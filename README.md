# CULITA

Figma 209:577 디자인을 구현한 반응형 브랜드 랜딩 페이지입니다.

## 실행

```sh
npm install
npm run dev
```

http://localhost:5173 에서 확인할 수 있습니다. Three.js 의존성을 처음 한 번 설치해야 합니다.

- 원본 Figma 이미지와 SVG를 assets/에 보관합니다.
- 메뉴 앵커 이동, 제품 상세 모달, 소개 슬라이드, TOP 이동을 지원합니다.
- 구매 버튼은 제품 영역으로 이동합니다. 결제 및 실제 상품 판매 기능은 연결되지 않았습니다.
- 모바일에서는 세로 카드 레이아웃으로 전환됩니다.

## 3D 병 연출

`bottle-scene.mjs`가 히어로와 소개 섹션 위에 투명 캔버스를 표시합니다. 스크롤 진행도에 따라 각 병이 한 바퀴씩 회전한 후 다음 모델로 전환되고, Shop 영역이 앞에서 덮으며 사라집니다. 기존 글자 핀 고정과 점선 연출을 유지합니다.

첨부 원본은 변경하지 않았습니다. 웹용 복사본에 Meshopt 압축, 메시 단순화, 2048px WebP 텍스처를 적용했습니다.

시스템에서 동작 줄이기를 선택하면 병 회전을 생략합니다. WebGL을 사용할 수 없으면 기존 소개 레이아웃이 표시됩니다.


### 병의 표면 표현

`bottle-materials.mjs`가 원본 모델의 삼각형을 보존하면서 높이를 기준으로 뚜껑과 몸통의 재질을 나눕니다. 원본 색상 텍스처를 유지하고 거칠기·색상 정보를 이용한 투과 마스크, 안쪽 액체 메시, 스튜디오 환경 반사를 적용합니다. 뚜껑은 불투명한 새틴 표면으로 표현하며 스크롤 회전과 제품 전환은 기존 흐름을 유지합니다.
